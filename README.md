## 🚀 Projetos em destaque

### 🤖 Sistema Multiagentes

Sistema de IA utilizando **LangGraph + LangChain**, com agentes especializados em pesquisa, análise crítica e redação trabalhando em fluxo colaborativo.

### 📚 Sistema RAG

Pipeline de **Retrieval-Augmented Generation** para consulta semântica de documentos utilizando LLMs, embeddings e recuperação contextual.

### 🌊 Machine Learning aplicado à Qualidade da Água

Pipeline de Data Science com **Random Forest, XGBoost, LightGBM e CatBoost**, feature engineering, validação cruzada e otimização de hiperparâmetros.

### 💳 Credit Scoring com Machine Learning

Sistema preditivo para análise de risco de crédito com pipeline completo de ML e aplicação interativa desenvolvida em **Streamlit**.

### ⚙️ API REST para Gerenciamento de Pedidos

Backend desenvolvido com **FastAPI, SQLAlchemy, JWT e SQLite**, incluindo autenticação, autorização e operações CRUD.
