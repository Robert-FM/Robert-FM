# 🚀 Projetos em Destaque

## 🤖 Sistema Multiagentes com IA

Sistema multiagente desenvolvido com **LangGraph e LangChain**, utilizando agentes especializados em **pesquisa, análise crítica e redação** organizados em um fluxo colaborativo baseado em grafo.

**Destaques:**

- 🧠 Arquitetura com **3 agentes especializados**
- 🔄 Pipeline `research → analysis → writing`
- 📈 **30% de melhoria** na qualidade das respostas em relação ao agente único
- ⚡ **20% de redução** no consumo médio de tokens
- 🛠️ LangGraph • LangChain • Gemini • Python

---

## 📚 Sistema RAG com LangChain

Sistema de **Retrieval-Augmented Generation (RAG)** para consulta semântica de documentos utilizando Python, LLMs e embeddings vetoriais.

**Destaques:**

- 🔎 Busca semântica em linguagem natural
- 🧠 Recuperação contextual com embeddings
- 📊 **Recall@5 de 87%**
- 🧩 Arquitetura modular e escalável
- 🛠️ Python • LangChain • Gemini • RAG

---

Pipeline completo de Data Science para classificação preditiva da qualidade da água.

## 💳 Credit Scoring com Machine Learning

- 📊 **F1-Score de 81,3%**
- 🌐 Aplicação interativa com Streamlit
- 🛠️ Python • Scikit-learn • Random Forest • Streamlit
